## 0. 最初に：因果関係の確認

「レビューがつかない → 売れない」ではなく、
**「売れていない → 母数が足りない → レビューがつかない」** の可能性が高い。

```
   ┌──────────────────────────────────────────┐
   │                                          │
   ▼                                          │
売れない ──→ 購入者が少ない ──→ レビューが付かない
   ▲                                          │
   │          信頼されない ←──── レビュー0件 ←┘
   └──────────────────────────────────────────┘
              ※ どこを先に切るかが勝負
```

### レビュー率の現実（業界でよく言われる目安・概算）

```
一般書籍     販売 1,000部 ──→ レビュー   5〜20件   (0.5〜2%)
塗り絵/高齢者向け             レビュー   2〜 5件   (0.2〜0.5%)
                              ↑ 購入者が高齢・ギフト購入が多く
                                そもそもレビューを書く習慣が薄い

→ 「レビュー10件」を自然発生で狙うなら 2,000〜5,000部級の販売が必要。
→ つまり自然発生を待つのは非現実的。「仕掛けて取りに行く」しかない。
```

### 3つのレバー（この順で同時に回す）

```
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│ ① 本の中に仕込む │ │ ② 自分の読者を  │ │ ③ 現場・施設から │
│                 │ │    作る         │ │                 │
│ コスト0・今日から│ │ 1〜3ヶ月        │ │ 最も濃い・最強   │
│ 効果：中        │ │ 効果：大        │ │ 効果：大         │
└─────────────────┘ └─────────────────┘ └─────────────────┘
        ＋
┌──────────────────────────────────────────────────────────┐
│ ④ レビューが0件でも売れる状態を作る（表紙・なか見・広告） │
│    ※ 実はここが一番の売上ボトルネックであることが多い     │
└──────────────────────────────────────────────────────────┘
```

## ⚠️ 大前提：Amazonの禁止事項（これをやると全レビュー削除＋アカウント停止）

| ❌ 絶対NG | 理由 |
|---|---|
| 金銭・商品券・割引・無料品と引き換えにレビュー依頼 | 対価付きレビューは規約違反 |
| 「★5でお願いします」と高評価だけ依頼 | 評価の誘導は違反 |
| 家族・友人・従業員にレビューを書いてもらう | 利害関係者レビューは違反 |
| 著者同士のレビュー交換（相互レビュー） | 違反。検知されている |
| 「不満な点は、レビューではなく直接ご連絡ください」 | 低評価の抑制＝違反 |
| レビュー代行業者の利用 | 違反。法的措置の対象にもなり得る |

| ✅ OK | 補足 |
|---|---|
| 本の中／外部で「率直なご感想をお寄せください」と中立に依頼 | 評価の方向を指定しない |
| 対価なしの献本（感想を書く義務を課さない） | 「書いてくれたら〇〇」はNG |
| 無料PDF配布（レビューと無関係に、リスト獲得目的で配る） | 交換条件にしないこと |
| Amazon Vine（※下記注意） | Amazon公式の唯一の例外プログラム |

> **Vineについての注意：** KDP向けVineは **amazon.com（米国）のKDPダッシュボード限定** の機能です。
> amazon.co.jp のVine（先取りプログラム）は**ブランド登録をしたセラー/ベンダー向け**で、
> KDP出版者は基本的に対象外。日本市場で狙うなら期待しない方が安全。
> （制度は変わるので、KDPダッシュボードに「Vine」表記が出ていないか定期確認する価値はあり）
>
> **もう一つ：** KDP著者には、セラーセントラルの「レビューをリクエスト」ボタンに
> 相当する機能が**ありません**。購入者に直接連絡する手段がゼロ。
> だからこそ「本の中」と「自分の読者リスト」が唯一の接点になります。

## ① 本の中に仕込む（コスト0・今日から・改訂して再アップするだけ）

1. **巻末に「感想のお願い」ページを1ページ丸ごと作る**
   - 隅に小さく書くのではなく、1ページ使う。高齢者向けなら文字は大きく。
   - レビュー直リンク：`https://www.amazon.co.jp/review/create-review?&asin=（自著のASIN）`
   - **QRコードを大きく載せる**（高齢者はURL手入力をしない。スマホのカメラでQRは読める）
   - 文言は中立に。例：
     > 「この本を最後まで楽しんでいただけましたか？
     >  よろしければ、率直なご感想をAmazonのレビュー欄にお聞かせください。
     >  いただいた声は、次の本づくりの何よりの参考になります。」

2. **巻頭（1〜2ページ目）にも1行だけ置く**
   - 塗り絵は「最後まで到達しない」人が多い。巻末だけだと届かない。

3. **【塗り絵の必殺技】「塗った作品の写真つきレビュー」を促す**
   - 画像付きレビューは、塗り絵というカテゴリでは**他の購入者への説得力が桁違い**。
     （「実際どんな絵なのか」「どのくらいの難易度か」が一目で分かる）
   - 文言例：「塗り上がった作品の写真を添えていただけると、
     これから選ぶ方の大きな参考になります」
   - ※写真投稿への謝礼は絶対に出さない（対価＝違反）

4. **「完成おめでとうページ／修了証」を巻末に**
   - 達成感が出た瞬間が、感想を書いてもらえる唯一のタイミング。
   - 修了証の下に感想依頼を配置する。

5. **奥付にYouTube・LINEのQRを併記** → 読者リストへの導線（②へ接続）

## ② 自分の読者リストを作る（1〜3ヶ月・ここが本丸）

**現状の最大の弱点：本を買った人と二度と連絡が取れない。** ここを壊す。

```
【今】  Amazon ──→ 購入者  …… 以降、接点ゼロ。レビューを頼む手段なし
                      ✕

【これから】
  YouTube ┐
  脳健康度 ├─→ LINE公式 / メルマガ ─→ 読者リスト ─┬→ 新刊告知（発売初日に売上集中）
  クイズ  ┘        （無料塗り絵PDF）              ├→ 「買ってくださった方へ、
  施設・講座┘                                     │   率直な感想を」と依頼
                                                  └→ 次作のテーマを読者に聞く
```

6. **LINE公式アカウントを開設する**（メルマガより優先）
   - 主要読者が高齢者／その家族なら、メールは開かないがLINEは見る。
   - 無料枠でも月200通まで配信可能。

7. **手元の「脳健康度セルフチェック」ページをリスト獲得の入口に改造**
   - 現状は診断結果を出して終わり＋YouTubeリンクのみ（`VIDEO_URLS` もプレースホルダのまま）。
   - 改造案：診断結果ページの最後に
     「結果に合わせた脳トレ塗り絵PDF（3枚）を無料でお送りします」→ LINE友だち追加ボタン
   - ※これは**レビューの対価ではなく、リスト獲得のための配布**。この線引きを厳守。

8. **YouTube @takedakikaku を塗り絵の入口にする**
   - 認知症予防チャンネルと塗り絵本は相性が完璧。
   - 出す動画：「塗り絵が脳に効く理由」「色鉛筆の選び方」「実際に塗ってみる10分」
   - 概要欄・固定コメントに本のリンクとLINE導線。
   - 動画の最後に「本を買ってくださった方、ぜひAmazonに率直な感想を」と一言。

9. **無料PDF塗り絵を「毎月1枚」配る** → リストが離脱しない。新刊時に一気に効く。

## ③ 現場・施設ルート（塗り絵カテゴリ最強のチャネル）

塗り絵本の本当の購買層は「個人」より「現場」。ここは競合がほぼ手をつけていない。

10. **デイサービス・介護施設・グループホームへのサンプル献本**
    - レクリエーション担当者が探しているのは、まさにこういう本。
    - 「感想を書いてください」と条件をつけない純粋な献本にする（規約対策）。
    - 献本時に「もし現場で使えたら、率直なご感想をAmazonに」と**お願いはできる**（対価なしなので可）。
11. **地域包括支援センター／認知症カフェ／家族介護者の会**
12. **図書館・公民館の講座**：「脳トレ塗り絵教室」を無料で開催 → 参加者がそのまま購入者＋感想源
13. **施設向けのまとめ買い提案**（10冊単位）→ 部数が動く

## ④ 商品自体を「レビューされやすく」設計する

塗り絵本の低評価・無反応の原因はほぼ決まっている。先回りで潰す。

| よくある不満 | 対策 |
|---|---|
| 裏写りする | **片面印刷**にする（明記して売る） |
| 線が細くて塗りにくい | 高齢者向けなら**線を太く**、面積を大きく |
| 難易度がバラバラ | 「やさしい→ふつう」の順に並べ、各ページに難易度表示 |
| 切り離せない／飾れない | ミシン目は無理でも「切り取り線」を印刷 |
| 何をすればいいか分からない | **「1日1枚・30日」の構成**にして完走を設計 |

14. **完走できる構成にする**（＝感想を書きたくなる状態を作る）
15. **シリーズ化する**：2冊目・3冊目を買った読者はレビュー率が跳ね上がる。
    同じ読者に何度も接触できるのがシリーズの本質。

## ⑤ レビュー0件でも売れる状態を作る（並行して必須）

**正直に言うと、塗り絵本の売上に最も効くのはレビューではなく「表紙」と「なか見検索」です。**
購入者は★の数より「中の絵が好みか」で買う。

16. **表紙をサムネイルサイズで勝負する**
    - スマホの検索結果で親指の爪ほどのサイズになる。その状態で
      「誰向けか・何が塗れるか・難易度」が分かるか？
    - 競合上位10冊の表紙を並べて、自分の本が浮くか埋もれるか確認する。
17. **「なか見！検索（Look Inside）」を必ず有効化**し、**一番自信のある絵を最初の数ページに置く**
    - 塗り絵はここで決まる。中身が見えない塗り絵本は売れない。
18. **A+コンテンツを入れる**（KDPでも無料で使える）
    - 完成見本の写真、対象年齢、片面印刷であること、難易度を画像で見せる。
19. **キーワード7枠とカテゴリ3つを見直す**
    - 例：「塗り絵 高齢者」「脳トレ 大人」「認知症 予防 塗り絵」「介護 レクリエーション」
    - 激戦カテゴリではなくニッチで1位を取る（ベストセラーバッジ＝レビューの代わりになる信頼記号）
20. **Amazon広告（スポンサープロダクト）を1日500円でテスト**
    - 目的は利益ではなく「初速の販売数」。売れれば自然検索順位も上がり、レビューの母数も増える。
21. **価格テスト**：塗り絵は1,000〜1,500円の心理的壁がある。数週間単位で検証。
22. **著者セントラルの整備**：著者ページ、プロフィール、全著書の紐付け。信頼記号になる。

## 効果測定（毎週これだけ見る）

```
┌─ 入口 ────────────────────────────────┐
│ ① 商品ページの表示回数（広告レポート）  │ ← キーワード/カテゴリの問題
└───────────────┬───────────────────────┘
                ▼
┌─ 転換 ────────────────────────────────┐
│ ② 販売数 ÷ 表示回数 ＝ 転換率           │ ← 表紙・なか見・価格の問題
└───────────────┬───────────────────────┘
                ▼
┌─ 蓄積 ────────────────────────────────┐
│ ③ レビュー数 ÷ 販売数 ＝ レビュー率     │ ← 本の中の仕掛けの問題
│ ④ LINE友だち数（自分の資産）            │ ← 長期の売上の源泉
└───────────────────────────────────────┘

※「①が低い」のに②③を直しても意味がない。必ず上から順に潰す。
```
