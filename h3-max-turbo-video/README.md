# H3 Max Turbo 告知動画 ― 解析と再現キット

アップロードされた14.4秒の動画を分解し、**同じ動画を作り直せる材料**を一式まとめたフォルダです。

| 項目 | 内容 |
|---|---|
| 尺 | 14.4秒（約24fps） |
| 解像度 | 1260 × 720（横長 16:9 に近い 7:4） |
| 音声 | BGM＋効果音のみ（ナレーションなし・推定）。0.4秒〜13.0秒に音があり、最後の1.4秒は無音 |
| 主題 | AI動画モデル「H3 Max Turbo」の新機能告知（速度2倍・コスト半分・品質ほぼそのまま・期間限定プロモーション） |
| ビジュアル様式 | **ペーパークラフト（切り紙）風の3D/ストップモーション調モーショングラフィックス** |

## このフォルダの中身

```
h3-max-turbo-video/
├── README.md          ← このファイル（解析レポート）
├── prompts.md         ← AI動画生成で再現するためのプロンプト（Seedance 2.0 / Higgsfield 向け）
├── storyboard.html    ← 絵コンテ（ブラウザで開くと18枚のキーフレームと構成が見られる）

├── frames/            ← 動画から切り出したキーフレーム18枚（0.3秒〜13.5秒）
├── audio/make_audio.py ← BGMと効果音を自動で合成して動画に乗せるスクリプト（外部音源不要）
└── variants/          ← 別商品向けの派生版（xmas-coloring-book：Japan Coloring Book クリスマスセール）
```

### 質感・ライティング

- すべてのオブジェクトが**厚さ1〜2mmの紙**として描かれ、下に短くやわらかい落ち影が落ちる。
- 紙の断面（白い縁）が見えるように少し斜めから照らされている。
- 背景紙には繊維の粒感。画面の四隅がわずかに暗い（ビネット）。
- カメラは固定。動くのはオブジェクトだけ（ストップモーション的）。

### 文字

- 日本語見出し：**極太ゴシック**（Noto Sans JP Black 相当）。文字も「切り紙」のように厚みと影がある。
- 英字ロゴ「H3 MAX TURBO」：太いサンセリフ、字間ややタイト。
- 文字の出方：**ポン！と弾む**（スケール 0 → 1.1 → 1.0 のオーバーシュート）か、**紙が折り畳まれて開く**（アコーディオン）。

### 主人公キャラクター

- 黒髪ボブの女性。コーラルのジャケット、白いインナー、青いワイドパンツ、クリーム色の靴。
- 関節（肩・肘・膝）に丸い「ピン」があり、紙人形として動く。
- 常に画面右側に立ち、オブジェクトを「持つ・押す・切る・丸める・掲げる」役。

### 構成を図にすると

```
  0s        3s          4.6s        6.8s        8.9s       10.2s      12.1s  14.4s
  │ 導入   │ 速度      │ コスト     │ 品質       │ 片付け   │ CTA       │ ロゴ │
  │AI UPDATE│ 2倍       │ 半分       │ ほぼ       │ くしゃ→  │ 今すぐ    │ H3   │
  │→朗報！ │ ⏱         │ ✂ タグ     │ そのまま   │ ゴミ箱   │ 試す      │ MAX  │
  │→登場   │           │            │ 🖼🖼        │          │ 🎀        │TURBO │
  ├────────┼───────────┼────────────┼───────────┼──────────┼───────────┼──────┤
   ▲高テンション  ▲3つの売り文句を「同じリズム」で連打（各1.1〜2秒）   ▲落ち着いて着地
```

- **リズム**：売り文句（速度→コスト→品質）はどれも「小道具が登場 → 文字がポン → 主人公がリアクション」の同じ型で1.1〜2.1秒ずつ。
- **転換は必ず"紙"で行う**：リボンワイプ、屏風開き、くしゃくしゃ、ページ折り。カット（ぶつ切り）は一度も使っていない。
- **エネルギー**：最初の3秒が最も密度が高く、中盤は一定、最後2秒はロゴのみで静止。

## 再現のしかた（ルート別）

### ① AI動画生成で再現する

`prompts.md` に、Seedance 2.0 の書式（ショット別タイムライン・エフェクト一覧・密度マップ・エネルギーアーク）で書いた英語プロンプトと、商品名や文言を差し替えるための日本語テンプレートがあります。

1. `prompts.md` の「フルプロンプト」をコピーして、Seedance 2.0 または Higgsfield の動画生成に貼り付ける。
2. 1回で14秒を生成できない場合は、「ショット別プロンプト」を使って 4〜5秒ずつ3本に分けて生成し、つなげる。
3. `frames/` の画像を**参照画像（スタイル参照）**として一緒に渡すと、色と質感が揃いやすい。

### ② Webアニメーションで再現する

`animation.html` をブラウザで開くと、動画と同じ構成・タイミングでアニメーションが再生されます。

- ファイル冒頭の `CONFIG` にある文字（「H3 Max Turbo登場」「速度」「2倍」など）を書き換えるだけで別の商品用に流用できます。
- 画面の「▶ 再生」で最初から、「⏸」で一時停止、タイムラインをドラッグで任意の秒に移動できます。
- 主人公キャラクターは簡略化した紙人形です（元動画ほど細かくは動きません）。

### ③ 動画編集ソフトで作り直す

`storyboard.html` の絵コンテと上のカット表がそのまま設計図になります。各カットの秒数・登場物・動きの種類を、After Effects や Canva のタイムラインに写してください。

## 解析で分かった細かい仕様

- 音声の波形を見ると、1.0〜13.0秒はほぼ一定の音量でBGMが流れ、カット替わり（0.4s / 0.9s / 1.6s / 3.0s / 5.6s / 10.0s 付近）に短いアタック音が乗っています。会話特有の「間」がないため、ナレーションは無いと判断しました。
- 料金カードの表記は「768p ｜ 1秒 ｜ $0.01」。1秒の768p動画が1セント、という意味の訴求です。
- ロゴのエンドカードは2秒（音は13.0秒で消え、最後の1.4秒は無音）。SNS広告として「最後にロゴだけ残す」定番構成です。
